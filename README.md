# Flutter Projects

Repositorio con múltiples proyectos de aprendizaje y práctica en Flutter.

## Proyectos incluidos

- `codelabs`: ejercicios y prácticas basadas en codelabs.
- `expense_tracker`: app de ejemplo para registro de gastos.
- `first`: primer proyecto de Flutter (introducción a widgets básicos).
- `flutter_internals`: experimentos con conceptos internos de Flutter.
- `meals`: app de recetas/comidas con navegación y filtros.
- `quiz_app`: app de cuestionarios.
- `roll_dice_app`: app simple para lanzar dados.
- `second`: segundo proyecto de Flutter con más widgets y layouts.

## Requisitos

- Flutter SDK instalado y configurado.
- Emulador o dispositivo físico para ejecutar las apps.

## Cómo ejecutar un proyecto

1. Entra al directorio del proyecto deseado, por ejemplo:

   ```bash
   cd expense_tracker
   ```

2. Obtén las dependencias:

   ```bash
   flutter pub get
   ```

3. Ejecuta la app:

   ```bash
   flutter run
   ```
